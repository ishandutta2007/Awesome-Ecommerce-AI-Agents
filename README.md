## 🌟 Top AI Agents for Ecommerce Ecosystem

**Autonomous AI Agents** are transforming online retail. This repository tracks notable **SaaS platforms** and **open-source projects** building the future of **Agentic Commerce**.

### 🔍 What are Ecommerce AI Agents?
Unlike basic chatbots, these agents handle:
- 🎧 **Customer Support:** Autonomous ticket resolution via Gorgias, Tidio, or Ada.
- 📦 **Order Management:** Tracking, refunds, and address changes.
- 📈 **Growth & Marketing:** Abandoned cart recovery and personalized outreach.
- 🤖 **Store Operations:** Automated inventory forecasting and product description generation.

## 💻 Open-Source GitHub Projects

### 🏗️ Dedicated Ecommerce AI Agent Frameworks

- **[MedusaJS](https://github.com/medusajs/medusa)** 🐚  
  The world's most flexible open-source commerce engine. Ideal for custom AI agents.
- **[Saleor](https://github.com/saleor/saleor)** ⚡  
  High-performance headless commerce with GraphQL.
- **[Vendure](https://github.com/vendure-ecommerce/vendure)** 📦  
  TypeScript-based framework designed for easy extension with LLMs.
- **[n8n](https://github.com/n8n-io/n8n)** 🔗  
  Self-hosted workflow automation. Use it to build "low-code" ecommerce agents.
- **[LangGraph](https://github.com/langchain-ai/langgraph)** 🧠  
  Build stateful, multi-agent workflows for complex store operations.
- **[CrewAI](https://github.com/crewAIInc/crewAI)** 🚢  
  Role-based multi-agent orchestration for marketing and support teams.
- **[Phidata](https://github.com/phidatahq/phidata)** 🐘  
  Add memory, tools, and knowledge to your commerce agents.

### 🔧 MCP Tools & Trust Infrastructure

- **[TWZRD Agent Intel](https://intel.twzrd.xyz)** — Trust scoring MCP for autonomous AI agents on Solana. Use `score_agent(wallet)` and `preflight_check(wallet)` (free) to verify purchasing or price-negotiation agent identity before executing transactions, and `get_trust_receipt(wallet)` for signed audit receipts via x402 micropayment. Prevents agent impersonation in automated ecommerce workflows. Config: `{"mcpServers":{"twzrd-agent-intel":{"url":"https://intel.twzrd.xyz/mcp"}}}`.
