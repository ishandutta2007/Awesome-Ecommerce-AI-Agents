# Awesome-Ecommerce-AI-Agents
## Top AI Agents for Ecommerce Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on AI Agents for Store Operations, Customer Support & Growth*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** building **AI Agents for Ecommerce**. These agents handle customer support, product recommendations, order management, inventory forecasting, personalized marketing, abandoned cart recovery, and autonomous store operations.

**Examples** include StoreClaw, Lindy.ai, Relevance AI, Gorgias AI Agent, Tidio (Lyro), Ada AI, and Gumloop (the category leaders). Tools listed here emphasize **agentic capabilities** (multi-step reasoning, real-time decision making, integration with Shopify/WooCommerce, and end-to-end automation).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, local LLMs (Ollama), full data privacy, and complete customization — ideal for ecommerce brands and developers who want sovereign AI agents without ongoing SaaS costs.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

### Dedicated Ecommerce AI Agent Projects

- **[MedusaJS](https://github.com/medusajs/medusa)**  
  Modular open-source headless commerce engine. Perfect foundation for building custom AI agents for product recommendations, order management, and customer support.

- **[Saleor](https://github.com/saleor/saleor)**  
  High-performance open-source headless ecommerce platform with GraphQL API, ideal for integrating autonomous AI agents.

- **[Vendure](https://github.com/vendure-ecommerce/vendure)**  
  TypeScript-based open-source commerce framework designed for flexibility and easy extension with AI agents.

- **[WooCommerce](https://github.com/woocommerce/woocommerce)** (with AI plugins)  
  Most popular open-source ecommerce solution. Extensible with local LLM agents for support, recommendations, and automation.

- **[n8n](https://github.com/n8n-io/n8n)**  
  Powerful open-source workflow automation tool with excellent LLM nodes. Widely used to build custom ecommerce AI agents and automations.

- **[LangGraph Ecommerce Agents](https://github.com/langchain-ai/langgraph)**  
  Stateful multi-agent framework for building reliable autonomous agents for cart recovery, personalization, and operations.

- **[CrewAI Commerce Templates](https://github.com/crewAIInc/crewAI)**  
  Role-based multi-agent orchestration with strong community examples for customer support, inventory, and marketing agents.

- **[OpenWebUI + Ecommerce Integrations](https://github.com/open-webui/open-webui)**  
  Full-featured local LLM interface that can be extended into powerful ecommerce assistants.

- **[Phidata Ecommerce Agents](https://github.com/phidatahq/phidata)**  
  Framework for building production agents with memory, tools, and knowledge tailored for commerce use cases.

### Additional Strong Open-Source Options

- **[Bagisto](https://github.com/bagisto/bagisto)** — Laravel-based open-source ecommerce with AI extension potential.
- **[Sylius](https://github.com/Sylius/Sylius)** — Symfony-based flexible ecommerce framework.
- **[Spree Commerce](https://github.com/spree/spree)** — Ruby on Rails headless commerce platform.
- **[Budibase](https://github.com/Budibase/budibase)** — Open-source low-code platform for building internal ecommerce tools and agent dashboards.
- **[LangChain + Shopify/WooCommerce APIs** templates for custom agents.
- Many community **Ollama + n8n** stacks for fully local ecommerce automation.

**Frameworks for building custom agents**: Combine **MedusaJS** or **Saleor** with **LangGraph**, **CrewAI**, and **n8n** + local LLMs (Ollama) to create fully sovereign, high-performance AI agents for your store.
